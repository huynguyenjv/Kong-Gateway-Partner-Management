🔄 Flow Onboarding Partner

📝 Giải thích:

  1. Create Client Credentials: Tạo Client ID & Secret cho partner authentication
  2. Create Consumer: Tạo Kong Consumer với CUSTOM_ID = CLIENT_ID
  3. ACL Plugin: Gán consumer vào ACL group để phân quyền
  4. Rate Limit Plugin: Apply rate limiting cho consumer
  5. Create Service: Định nghĩa upstream service backend
  6. Create Route: Tạo route mapping từ Kong đến service
  7. OIDC Plugin: Enable OAuth authentication cho route

📝 Request Flow:

  1. Route Matching: Client request → Kong nhận dạng route phù hợp
  2. OIDC Plugin: Verify access token (Bearer token từ /oauth/token)
  3. Consumer Identification: Extract consumer từ token
  4. ACL Plugin: Check consumer có quyền truy cập route không
  5. Rate Limiting: Kiểm tra request quota của consumer
  6. Gateway Service: Define backend objective
  7. Kong Gateway Boundary: Forward request đến upstream backend
  8. Upstream Backend: Process request và trả response
  9. Response Plugins: Apply response transformation nếu có
  10. Final Response: Trả kết quả về client

📝 Architecture Components:

🔌 Kong API Gateway
  • Authentication: OAuth 2.0, JWT, API Keys
  • Rate-Limiting: Per consumer, per route
  • Monitoring: Metrics, logging, analytics
  • Caching: Response caching layer
  • Plugins: ACL, KEY-AUTH, OIDC, etc.
🎯 Backend Services
  • Monolithic: Single large application
  • Microservices: Multiple independent services
  • Serverless: AWS Lambda, Cloud Functions
  • Load Balancing: Distribute traffic across instances
👥 Clients
  • Web/Mobile Apps: iOS, Android, Web browsers
  • Third-party Integrations: Partner systems
  • Internal Services: Other microservices
